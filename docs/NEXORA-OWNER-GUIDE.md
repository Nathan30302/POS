# NEXORA — How to use (daily guide)

Plain English for owners and cashiers: **what to click**, **what the words mean**, and **what each screen does**.

For real screenshots + voice walkthrough: open **/guide** or **Settings → How to use**.  
Downloadable PDF: `/docs/NEXORA-Owner-Guide.pdf`.

---

## 1. The big idea (one minute)

| Room in NEXORA | What it is |
|----------------|------------|
| **Sell** | The till — customers pay here |
| **Inventory** | The storeroom on screen |
| **Command** | Owner’s desk — “how is my shop?” |
| **Pulse** | Wise friend — “what should I worry about?” |
| **Ledger** | Past sales — reprint or void |
| **Audit / Trust** | Diary that is hard to erase |
| **Team** | Who has the keys |

A basic POS often only remembers “someone paid.” NEXORA also remembers **who**, **when**, **why** (voids / big discounts), and **what that means for your money**.

## 2. Your day, start to finish (click this order)

Train every new cashier on this first.

### Morning
1. Login → email + password → Sign in.
2. Tap **Sell** (sidebar on laptop, bottom bar on phone).
3. If you use cash: type **Opening float** (example 100) → tap **Open shift**.
4. Owner (optional): open **Command** once — glance at Money leaks.

### During the day
5. Scan or search a product → it appears in the cart.
6. Tap **Cash** (or MoMo / Card / Credit) → tap **Complete**.
7. Show the receipt with **your** shop name.
8. If Wi‑Fi dies: the sale can **queue**. Do **not** type the same sale again when it syncs.

### When something goes wrong
9. Wrong sale after Complete? **Ledger** → open the sale → **Void** → write a reason (Manager PIN if asked).

### Evening
10. On Sell: **Close shift** → enter counted cash.
11. Owner: **Command** → Money leaks / Trust. **Pulse** → Refresh if needed.

> **Opening float** = cash already in the drawer before the first customer.  
> **Open shift** = start counting that cash session.  
> **Close shift** = end-of-day count vs expected cash.

## 3. Word meanings (dictionary)

| Word | Means | Where |
|------|--------|--------|
| **Sell** | The till / checkout | Sidebar · phone bottom bar |
| **Cash drawer / Opening float** | Starting cash in the till | Sell → shift card |
| **Open shift** | Start the cash session so end-of-day has a target | Sell |
| **Close shift** | End the session and count the drawer | Sell |
| **Complete** | Finish the sale: payment, stock drop, receipt | Sell · cart |
| **Exact / Cash Received** | Exact = paid total with no change. Cash Received = notes handed over | Sell · cart |
| **Discount** | Reduce price; big ones need permission + reason | Sell · cart |
| **Void** | Cancel a finished sale; always write a reason | Ledger |
| **Manager PIN** | Short code to approve voids / big discounts | When asked |
| **Command** | Owner desk: money, leaks, Trust | Sidebar |
| **Money leaks** | Warnings that profit is escaping | Command · Pulse |
| **Critical** | Serious leak — act today | Money leaks |
| **Trust** | Soft alarm for odd voids / discounts | Command |
| **Ledger** | Past sales; reprint or void | Sidebar |
| **Receive** | Add stock from a delivery | Inventory |
| **Low stock** | At/under warning level — reorder | Inventory |
| **Queued / offline** | Sale saved on device; syncs later — don’t re-enter | Sell |
| **Audit** | Who did what, when | Sidebar |
| **Credit sale** | Customer pays later | Sell · payment |
| **Branch** | One physical location | Account · Settings |

## 4. Sell — what to click

1. Sidebar → **Sell**.
2. If needed: Opening float → **Open shift**.
3. Search box → scan barcode OR type name → Enter (or tap a product tile; hold for +5).
4. Optional: type customer phone.
5. Cart → Cash / MoMo / Card / Credit / Other.
6. If Cash: **Exact** or type **Cash Received**.
7. Tap **Complete** → print/share receipt.

**Words on Sell:** No open shift / CLOSED = session not started. Link phone / QR = phone for camera scanning. Subtotal / Discount / Total = amounts. Prices come from the server — you cannot invent a cheaper price.

---

## 5. Command — owner desk

1. Sidebar → **Command**.
2. Choose Today / 7 days / 30 days.
3. Read KPIs: Revenue MTD, Gross profit, Live today, Avg ticket.
4. **Money leaks** → open any **Critical** card.
5. **Trust** → tap a flagged cashier → review Ledger.
6. Multi-branch: compare Main vs other cards.

**MTD** = month to date. **Live today** = only today. **Void %** / **Discount %** = cancellation and price-cut share.

**Leak signals:** Critical selling below cost · one cashier always highest void % · discount % far above others · stock falling while tickets look tiny · short closes.

## 6. Inventory, Ledger, Pulse, and the rest

### Inventory
1. Inventory → search or **Add product**.
2. Open product → **Receive** → quantity → confirm.
3. Watch **Low stock**; use Pulse for reorder ideas.

### Ledger
1. Ledger → date chip → optional search.
2. Tap sale → reprint or **Void** + reason (+ PIN if asked).

### Pulse
1. Pulse → **Refresh Pulse**.
2. Read health / leaks → reorder → try **Ask**.

### Customers
1. Add customer (name + phone).
2. On Sell: type that phone before Complete.
3. Weekly: check **Overdue**.

### Team
1. Invite staff → role → permissions (cashiers often Sell only).
2. Set **Manager PIN**.

### Expenses
1. **Record expense** → amount, category, note.
2. Optional: Export CSV.

### Audit
1. From Trust or a dispute → Audit around that time.
2. Check **Conflicts** after offline days.

### Settings
1. Edit **Business name** (prints on receipts) → Save.
2. MoMo numbers, branches, themes.
3. Open **How to use** for this guide with voice.

## 7. Two kinds of accounts

| Who | Where | What |
|-----|-------|------|
| Shop owner / staff | Sell, Command… | Run *one* business |
| Platform admin | `/platform` | Approve shops, suspend, record payments |

Signup → **Pending approval** (no auto-login) → platform **Approve** → **Trial** → Sign in. **Reject** → cancelled.

Create **your** shop for real use. Demo is only for trying the product.

## 8. Security — three locks

1. **Permission** — not everyone can void or discount heavily.  
2. **Reason** — voids/discounts leave a sentence in the diary.  
3. **Pattern** — Trust & Money leaks notice odd rates.

NEXORA makes theft louder and slower — enough for a careful owner.

## 9. Train a cashier in 10 minutes

1. How to use → “Your day, start to finish” → **Voice**.
2. Sell → Opening float → Open shift.
3. Two items → Exact → Complete → show receipt.
4. Show Command Money leaks once.
5. Rule: never void without calling the owner — the system remembers.
