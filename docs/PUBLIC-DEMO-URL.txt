--- Always-on deploy (mandatory for laptop-off) ---

Option A — Fly.io (configs in-repo: Dockerfile, fly.toml, scripts/docker-entrypoint.sh)
  1. Install a working CLI:
       curl -L https://fly.io/install.sh | sh
       # or: brew install flyctl
  2. Login (opens browser):
       fly auth login
  3. From /Users/mac/POS:
       fly apps create nexora-shop-demo
       fly volumes create nexora_data --region jnb --size 1
       fly secrets set \
         JWT_SECRET="$(openssl rand -hex 32)" \
         MOMO_WEBHOOK_SECRET="$(openssl rand -hex 24)" \
         CORS_ORIGIN="https://nexora-shop-demo.fly.dev" \
         SHOP_PUBLIC_ORIGIN="https://nexora-shop-demo.fly.dev" \
         DATABASE_URL="file:/data/nexora.db" \
         SEED_ON_BOOT=1
       fly deploy
  4. Expected URL: https://nexora-shop-demo.fly.dev
     Update CORS/SHOP_PUBLIC_ORIGIN if the hostname differs.
  5. Verify:
       curl -sS https://nexora-shop-demo.fly.dev/api/health
       curl -sS -o /dev/null -w "%{http_code}\n" https://nexora-shop-demo.fly.dev/login

Option B — Railway (railway.json + same Dockerfile)
  1. railway login
  2. Attach a Volume mounted at /data
  3. Set the same env vars with your Railway public URL for CORS / SHOP_PUBLIC_ORIGIN
  4. Deploy

Honest constraint:
  A tunnel to localhost CANNOT survive laptop-off. Cloud hosting + account login is required.
