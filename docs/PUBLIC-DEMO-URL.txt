--- Always-on deploy (mandatory for laptop-off) ---

Option A — Fly.io (Dockerfile, fly.toml, scripts/docker-entrypoint.sh)
  1. curl -L https://fly.io/install.sh | sh
  2. fly auth login
  3. fly apps create nexora-shop-demo
  4. fly volumes create nexora_data --region jnb --size 1
  5. fly secrets set \
       JWT_SECRET="$(openssl rand -hex 32)" \
       MOMO_WEBHOOK_SECRET="$(openssl rand -hex 24)" \
       CORS_ORIGIN="https://nexora-shop-demo.fly.dev" \
       SHOP_PUBLIC_ORIGIN="https://nexora-shop-demo.fly.dev" \
       DATABASE_URL="file:/data/nexora.db" \
       SEED_ON_BOOT=1
  6. fly deploy
  7. Share https://nexora-shop-demo.fly.dev
     PDF: https://nexora-shop-demo.fly.dev/docs/NEXORA-for-business.pdf

Option B — Railway: railway login && railway up (see railway.json); volume at /data.

Honest constraint: laptop-off requires cloud hosting + account login. No workaround.
