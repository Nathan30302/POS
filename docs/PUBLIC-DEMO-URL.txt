--- Always-on deploy (required for laptop-off) ---

Option A — Fly.io (preferred; configs are in-repo)
  1. Install:  curl -L https://fly.io/install.sh | sh
  2. Login:    fly auth login
  3. Create:   fly apps create nexora-shop-demo
  4. Volume:   fly volumes create nexora_data --region jnb --size 1
  5. Secrets:
       fly secrets set \
         JWT_SECRET="$(openssl rand -hex 32)" \
         MOMO_WEBHOOK_SECRET="$(openssl rand -hex 24)" \
         CORS_ORIGIN="https://nexora-shop-demo.fly.dev" \
         SHOP_PUBLIC_ORIGIN="https://nexora-shop-demo.fly.dev" \
         DATABASE_URL="file:/data/nexora.db" \
         SEED_ON_BOOT=1
  6. Deploy:   fly deploy
  7. URL:      https://nexora-shop-demo.fly.dev
     (update CORS_ORIGIN / SHOP_PUBLIC_ORIGIN if the app name differs)

Option B — Railway
  1. railway login && railway init (or connect the GitHub/Origin repo in the dashboard)
  2. Required: Service → Settings → Volumes → Add Volume → Mount path: /data
     (Dockerfile must NOT declare VOLUME — Railway rejects that instruction.
      App writes SQLite to DATABASE_URL=file:/data/nexora.db and uploads to /data/uploads.)
  3. Variables (same as Fly secrets above; use your Railway public URL for CORS /
     SHOP_PUBLIC_ORIGIN). Railway sets PORT automatically; SERVE_SPA=1 is in the image.
  4. Deploy from the linked repo (Dockerfile + railway.json). Entrypoint runs
     prisma db push + optional seed, then serves API+SPA on 0.0.0.0:$PORT.

Honest constraint:
  A tunnel to localhost CANNOT survive laptop-off. Cloud hosting is mandatory.
