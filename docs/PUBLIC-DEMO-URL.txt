--- Always-on deploy (required for laptop-off) ---

Option A — Fly.io (preferred; configs are in-repo)
  1. Install:  curl -L https://fly.io/install.sh | sh
  2. Login:    fly auth login
  3. Create:   fly apps create nexora-shop-demo
  4. Volume:   fly volumes create nexora_data --region jnb --size 1
  5. Secrets:
       fly secrets set \
         JWT_SECRET="$(openssl rand -hex 32)" \
         MOMO_WEBHOOK_SECRET="$(openssl rand -hex 24)" \
         CORS_ORIGIN="https://nexora-shop-demo.fly.dev" \
         SHOP_PUBLIC_ORIGIN="https://nexora-shop-demo.fly.dev" \
         DATABASE_URL="file:/data/nexora.db" \
         SEED_ON_BOOT=1
  6. Deploy:   fly deploy
  7. URL:      https://nexora-shop-demo.fly.dev
     (update CORS_ORIGIN / SHOP_PUBLIC_ORIGIN if the app name differs)

Option B — Railway
  railway login && railway init && railway up
  Set the same env vars; attach a volume at /data if using SQLite.
  Config: railway.json + Dockerfile

Honest constraint:
  A tunnel to localhost CANNOT survive laptop-off. Cloud hosting is mandatory.
